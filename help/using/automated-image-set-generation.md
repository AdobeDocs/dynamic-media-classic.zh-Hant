# 自動產生影像集{#automated-image-set-generation}

<!-- 

Comment Type: remark
Last Modified By:

<p>New for 6.5</p>

 -->

您可以將集合產生作為不依存於上載的獨立工作來自動化。

**自動產生影像集：**

1. 移至&#x200B;**[!UICONTROL 檔案]** > **[!UICONTROL 產生集]**。
1. 在「產生集」對話框中，指定工作名稱。

   依預設，系統會為工作指派名稱，以指出它是已產生的工作，以及產生工作的時間。

1. 選取要套用的預設集。
1. 選取&#x200B;**[!UICONTROL 目的地資料夾]**，然後指定您要使用的資料夾。
1. 選取&#x200B;**[!UICONTROL 提交]**。
